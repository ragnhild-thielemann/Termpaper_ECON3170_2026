# Termpaper_ECON3170_2026


#Prosjektbeskrivelse

Jeg skal sentrere prosjektet rundt tre spørsmål: 
1. Fyllingsgrad i November mot prisvolaliteten. 
  - Har høy vannfyllingsgrad i starten av tappesesongen sammenheng med lavre prisvolaliteten gjennom vinteren?
    - Fyllingsgrad i november, Volatilitet gjennom vintren

2. Hvordan påvirker europeiske kraftpriser norsk vannkraftproduksjon og magaintapping? Har prisene blitt mer volatile etter at vi oprettet utenlandskablene?
  - P_EU_t, P_NOR_t, Prod_NOR_t, Fylling-t, Eksport_t, nett-kapasitet
  
Også se på energimiksen i ulike prisområder.
